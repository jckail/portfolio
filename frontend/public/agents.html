Connect your assistant

Give your assistant direct access to my public experience, projects, education, and skills. These interfaces are read-only and use the same portfolio content as this site. No API key is required.

MCP

In a client that supports remote MCP over Streamable HTTP, add this server URL:

https://www.jckail.com/mcp

Client support varies; this server provides public tools and resources without OAuth. If your client requires OAuth or does not support Streamable HTTP, use the JSON or plain-text links below.

Example configuration for clients that accept an HTTP MCP server:

{
  "mcpServers": {
    "jordan-kail": {
      "type": "http",
      "url": "https://www.jckail.com/mcp"
    }
  }
}
  • get_portfolio_context — all context or one section.
  • search_portfolio — search public facts, returning up to 10 matches.
  • portfolio://jordan-kail/context — public context resource.

Try: “Summarize Jordan's agent-platform experience and link to the source projects.”

GraphQL

Send a query to /graphql. The schema supports queries and introspection; mutations and subscriptions are unavailable.

curl https://www.jckail.com/graphql \
  -H 'Content-Type: application/json' \
  --data '{"query":"{ profile { name title location summary } experience { company title highlights } projects { title url } education { institution study date } skillGroups { name items } }"}'
