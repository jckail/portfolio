MCP

In a client that supports remote MCP over Streamable HTTP, add this server URL:

https://jordankail.ai/mcp

Client support varies; this server provides public tools and resources without OAuth. If your client requires OAuth or does not support Streamable HTTP, use the JSON or plain-text links below.

Example configuration for clients that accept an HTTP MCP server:

{
  "mcpServers": {
    "jordan-kail": {
      "type": "http",
      "url": "https://jordankail.ai/mcp"
    }
  }
}

GraphQL

Send a query to /graphql. The schema supports queries and introspection; mutations and subscriptions are unavailable.

curl https://jordankail.ai/graphql \
  -H 'Content-Type: application/json' \
  --data '{"query":"{ profile { name title location summary } experience { company title highlights } projects { title url } education { institution study date } skillGroups { name items } }"}'
